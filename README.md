## 📥 Installation Guide (For Optimal Performance)
To avoid Windows security conflicts and ensure smooth auto-startup:

1. Download the application from the **Releases** section.
2. **Important:** Extract or move the application folder to an independent path away from system-protected folders (e.g., create a new folder in `D:\` or directly in `C:\`, avoiding `C:\Program Files`).
3. Run the executable file.

## ⚙️ How to Enable Auto-Startup
1. Press `Win + R`, type `shell:startup`, and hit Enter.
2. Create a shortcut of the executable file and paste it into this folder.
